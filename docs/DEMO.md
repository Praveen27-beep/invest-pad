# Demo script (about 8 minutes)

Use the fictional company in `backend/eval/corpus.py` or your own material. No real
client data. Say once at the start: this is a research tool, it does not give advice.

1. **Home → add a company.** Point at the getting-started list.
2. **Documents → upload** an annual report PDF. Show passages appear in search.
3. **Notes → write a note** with a `[[link]]` to another note; show backlinks.
4. **Thesis & decisions → write the thesis**, add two assumptions (one sourced fact,
   one judgement), attach a passage as evidence for the fact.
5. **Record a decision**: "Bought", the one decisive reason, what would change my mind.
   If "How I invest" is written and a model is connected, show the guardrail questions.
6. **Overview** — the success test: "come back in six months". The decisive reason,
   what it rested on and how each assumption stands now, without opening a document.
7. **Ask** a question with a model connected: cited claims; click a citation. Ask
   "should I buy it?" — refused.
8. **Documents → Check against my assumptions** on a newer document; accept or dismiss a
   suggestion in the thesis tab.
9. **Checklists**: run the forensic checklist; edit it and add a question.
   **Numbers**: DuPont or Beneish with the formula on screen.
10. **Portfolio**: import a holdings CSV, turn on a 10% single-position limit, acknowledge
    an alert with a note. **Review**: this month's questions.
11. **Connections** graph; **Journal** across companies.
12. **Settings**: export everything (ZIP), the MCP connection for Claude, delete account.
